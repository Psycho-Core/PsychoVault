# S070 owned rendering regressions

This suite compares images generated by the owned headless renderer with
checked-in project baselines. Each case also has pixel probes and, where useful,
frame/state assertions. A mismatch exits nonzero, writes a red-on-black diff
and records the case in `report.json`. This is a regression suite, **not** a
comparison against an independent browser or the legacy UI.

## Run locally

From the repository root, with Python 3 and a supported compiler:

```sh
python3 tools/Psycho_build.py --target engine --outdir build
python3 tests/Psycho_golden_tests.py
python3 tools/Psycho_golden.py --engine build/pv-engine --outdir build/golden-results
```

On Windows use `python` and `--engine build/pv-engine.exe`. The manual-only
owned-engine Windows workflow runs these checks after building. Output and diff
images live in the chosen output directory, which must be outside `baselines`.
A missing/corrupt baseline, renderer error, failed probe, wrong dimensions or
any changed pixel fails the run. No comparison tolerance is applied. To review
potential baseline changes without changing checked-in references, run with
`--candidates` and inspect `OUTDIR/candidates/`; copying a candidate into the
repository is a separate, deliberate review action.

## Fixture map and scope

| Step | Rendering scenario | Additional check |
| --- | --- | --- |
| S052 | Custom property, calc, padding and border | Color probes |
| S053 | Hover/important cascade | Hover color probe |
| S054 | Border-box and overflow clip | Inside/outside probes |
| S055 | Flex grow and gap | Three item colors |
| S056 | Grid tracks and gap | Four cell colors |
| S057 | Absolute positioning and z-order | Overlap probes |
| S058 | Rounded outline and translated painting | Shape probes |
| S059 | Nested wheel scroll and scrollbar | Scrolled colors |
| S060 | Click dispatch and DOM style mutation | Title and color |
| S061 | Checkbox state and adjacent checked selector | Checked-state color |
| S062 | Input edit and input event | Value/title and color |
| S063 | Supplied PNG resource and scaling | Image paint command |
| S064 | Resolution media query at DPR 2 | Color probe |
| S065 | Reduced-motion media query suppressing animation | Color probe |
| S066 | Hover mutation and incremental repaint | Nonempty local damage tiles |
| S067 | Fixed/effect content and unchanged frame | Fixed/effect counters and empty damage |
| S068 | Canvas clipping and fill | Canvas command and colors |
| S069 | Bundled UI font family/weight | Font fields in paint frame |

The common baselines were captured from the owned Linux renderer at the S070
fixture implementation and visually inspected with explicit pixel probes. The
Windows font image was captured on `windows-2022` in push-triggered Actions run
43513145650 (commit `4d7ec21`); Windows checkbox and input images were captured
in run 43514286211 (commit `73fa6fb`). These Windows images reflect DirectWrite
and are selected only on Windows; other images are shared. The portable S069
baseline intentionally contains no glyphs because the portable engine has no
text raster backend. S069's Windows baseline contains real bundled-font text.
Baselines describe current engine behavior and are not independent proof that
this behavior is standards-conformant.

Cases deliberately cover a narrow subset of each step. They do not prove
scroll anchoring, full animation timing, selection/IME, display-list caching,
actual compositor presentation/dropped frames, physical DPI changes, CSS/font
conformance or visual parity. Font output can differ across Windows versions or
system font/fallback updates, so an exact pixel difference needs investigation,
not an automatic baseline refresh. Full reference screenshot comparison is
S071, and the broader P2 exit gate remains open.
