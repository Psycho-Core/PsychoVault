- Centered Proton VPN when its popup is opened as a full tab and moved the optional Proxy Switch into an explained Advanced section.
- Removed the misleading Proton store button; bundled Proton can still be restored from Settings.
- Added exact-origin controls for camera, microphone, location and notifications. Default follows the global permission settings.
- Added a local domain list and exact site exceptions for the built-in blocker. These are not uBlock Origin filters.
- Added custom sleeping-tab idle times and hostname exclusions. Sleeping still reloads a tab and can lose unsaved form data.
- Added an updater VPN troubleshooting note. An installer saved by the new updater is eligible for cleanup after the updated version starts and the installer is verified unchanged. Older untracked installers are kept.

- Added a VPN check tab: opt-in public-IP comparison through ipapi.co, an external DNS test link and an opt-in WebRTC candidate check. None proves the absence of leaks.
- Added encrypted password backups, CSV import with duplicate skipping, atomic vault writes and a rollback journal for interrupted encryption changes. Keep backup passwords safe; they cannot be recovered. CSV exports are plaintext.
- Added crash snapshots of normal windows only and a choice of tabs to restore. Snapshots can be up to five seconds old.
- Added active download progress, speed and pause/resume where Electron supports it. An interrupted transfer can only be resumed while its DownloadItem remains available; retry after restart is not supported.
- Added custom HTTPS search shortcuts, such as gh words.

DNS testing opens a third-party test and must be interpreted by the user. Live Proton leak checks and an installed-version update were not independently tested.
