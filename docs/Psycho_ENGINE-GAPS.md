## S051 follow-up — Windows DirectWrite complete, 2026-11-07

## S052 follow-up — CSS values implementation, 2026-11-07

S052 now implements the planned CSS-values subset in the owned engine:

- CSS declarations are tokenized at top-level delimiters while respecting quotes and balanced functions, preserving source order and `!important` (including commas/semicolons inside functional values).
- Custom properties preserve case, cascade with importance, inherit through the DOM, resolve recursively through `var()` with fallbacks/cycle protection, and are recomputed after inline `style.setProperty` mutation.
- Lengths support recursive `calc()`, `min()`, `max()` and `clamp()`, common absolute units, `em`/`rem`, viewport units, percentages, and mixed-unit width/height expressions. Width and height percentage expressions are resolved against the containing block during layout when that basis is available.
- Color parsing now covers the common named-color subset, 3/4/6/8-digit hex, comma/space `rgb[a]()` and `hsl[a]()` including alpha, plus `currentColor` use in computed paints.
- The implementation expands 1–4 value margin/padding/border-width shorthands, border and side-border shorthand, `font`, and one/two-value `gap`. These are targeted engine behaviors, not full CSS conformance.
