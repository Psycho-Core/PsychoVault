# S070 — owned rendering goldens

I added 18 small deterministic HTML/image fixtures, one each for S052–S069, with checked-in RGBA PNG baselines. `tools/Psycho_golden.py` runs the headless renderer, checks fixed semantic pixel/metadata probes, compares decoded pixels exactly, and emits a JSON report, actual images, and red-on-black diffs on mismatch. Candidate generation writes to a separate output directory and does not update baselines. `tests/Psycho_golden_tests.py` checks PNG round trips/corruption, pixel differences, missing engines/baselines, failure reporting, output safety, and coverage mapping.

The headless renderer now reconstructs the frame's actual fixed/effect/font fields and supports explicit hover/click/wheel/key/text/render actions plus scroll and DPR/reduced-motion inputs. The parked manual Windows owned-engine workflow runs the golden suite and preserves reports and images on failure. Local commands, case descriptions, baseline provenance and update instructions are in `tests/golden/README.md`.

Linux: `python3 tools/Psycho_build.py --compiler gcc --target engine --outdir /tmp/pv-s070-engine`, `python3 tests/Psycho_golden_tests.py`, and `python3 tools/Psycho_golden.py --engine /tmp/pv-s070-engine/pv-engine --outdir /tmp/pv-s070-check` passed **6 harness self-tests and 18/18 goldens**. Linux intentionally does not rasterize text; its S069 golden covers layout/background and paint metadata only.

Windows baseline capture found expected DirectWrite differences for the checkbox, input text, and bundled-font cases, so these have separate Windows goldens; common cases remain pixel-exact. The baseline captures were generated by the current engine and inspected with fixed semantic probes, not by a browser reference. Windows CI validation is being completed separately.

This is representative coverage per step, not comprehensive coverage of all features within S052–S069. In particular it does not validate detailed selection/IME painting, full animation timing, real compositor pacing/drop behavior, physical multi-monitor DPI, or visual parity against the reference. S071 and the broad P2 exit gate remain open.
