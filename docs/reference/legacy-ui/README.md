# My legacy UI reference

I captured these screenshots from my old Windows application before I wiped the old source. I used a throwaway profile, not my personal profile.

I am keeping them as a visual contract for the new browser. They are not screenshots of the new engine, and I will not publish them as if they are.

The capture manifest is `CAPTURE.json`. The file hashes, dimensions and source commit are recorded in `../legacy-inventory.json`.

The archive covers the new-tab/home page, the browser window and all ten settings categories. Some settings pages are longer than one viewport, so I still need full-page captures before I sign off complete visual parity.
