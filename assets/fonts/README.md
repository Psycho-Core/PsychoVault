# Bundled UI font

`Inter-Regular-variable.ttf` is the unmodified `Inter[opsz,wght].ttf` from
[Google Fonts at commit 29b4ec6df2522a8aee279414b78a07910b065874](https://github.com/google/fonts/tree/29b4ec6df2522a8aee279414b78a07910b065874/ofl/inter).
It is copyright 2020 The Inter Project Authors and distributed under the SIL
Open Font License 1.1, included verbatim as `OFL.txt`. It is a font asset, not
application code. SHA-256: `29160a80ff49ddcab2c97711247e08b1fab27a484a329ce8b813d820dc559031`.
The license SHA-256 is `5b9321a4298cfeb6b34354164a1c3afc3db114569984c502b9b35d988fd58c57`.

The Windows MSVC build embeds the font and license as `RCDATA` resources 101
and 102, respectively, in each executable; the preview ZIP also includes the
license as `licenses/Inter-OFL.txt`. No user or system font installation is
performed. The family alias used by the app page is `PsychoVault UI`.
