Extensions

Chrome-style extensions, loaded the way Chromium's own "load unpacked" works: install a folder, or a .crx file (this unpacks it, because Electron refuses crx files outright). Extensions run inside every tab and can read the pages you visit - only install ones you trust, and note that no signature is verified for a crx here.
What actually works. Content scripts, page changes, request blocking through the old webRequest API, storage, messaging, and - through PsychoVault's own shim - chrome.proxy and chrome.privacy, which is what a browser VPN extension needs to send traffic through a tunnel. What does not exist in this engine: declarativeNetRequest (the MV3 rules engine), native messaging, chrome.vpnProvider, and a toolbar to click. Every extension below is checked against that list, and anything it needs that is missing is named under it rather than left to fail silently.
Proton VPN

Installed by default. PsychoVault ships a build of Proton's own browser extension, compiled from Proton's GPL-3.0 source at github.com/ProtonVPN/proton-vpn-browser-extension. It appears in the list below like any other extension - open its window to sign in and connect.

You need your own Proton account. Sign in with it in the extension window; PsychoVault does not see, store, or ship your Proton password, and no subscription or server list is bundled. Traffic is then routed by Chromium through Proton's proxy - the same mechanism the extension uses in Chrome.

If the VPN says connected but your IP does not change, press Check what proxy is in use. It reports what Chromium would really do with your traffic, per profile.

Spelling

Spell-check text you type in pages
Turns the whole feature on or off: red underlines in a page's own fields, the suggestions in the right-click menu and “Add to dictionary”. The address bar, the palette and this page are deliberately not checked.
PsychoVault's own checker
This is what actually draws the red line and offers “the” for “teh”: a 15,000-word frequency list plus your own words, checked in the page. Electron builds ship no dictionary and cannot download one, so without this the spellchecker is a flag with nothing behind it. Turn it off only if you have patched dictionaries in yourself.
Languages
Which language the browser is told to check, and which word list the built-in checker prefers: en uses the English list, de falls back to "no dictionary for this language" because only English ships here. Blank uses your system locale; case does not matter.
Dictionary source
A folder or mirror holding <lang>.dic and <lang>.aff Hunspell files. Kept because it is the knob Chromium documents, but an Electron build has no dictionary downloader: nothing is fetched from here, and <profile>/Dictionaries is not read either - all three were tested. The built-in checker above is what makes the feature work.

About

PsychoVault
Browser application (this UI, tabs, bookmarks, history, downloads, blocking): written for this project.
Rendering engine: Chromium, via Electron 45.
Bookmark, history and settings files live in your user data folder.
Licensed MIT. Chromium components under their own licences - see THIRD-PARTY-NOTICES.md.
Automatic updates
Checked quietly once at startup, and only on packaged Windows x64 builds. This runs the same check and tells you the answer even when it fails.
Release access token
Only needed when the repository is private: GitHub answers 404 to an unauthenticated release lookup. A read-only token makes the check work. It is stored in your profile, encrypted with the OS keychain where one exists, and it is never shown again after saving. It cannot make a bad update trusted - the Ed25519 signature on the manifest still decides that.
